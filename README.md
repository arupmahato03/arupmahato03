# 🚀 TradeDrift

### Trading Journal & Backtesting Platform

**Backend Engineer · Personal Project** &nbsp;·&nbsp; [tradedrift.in](https://tradedrift.in)

Traders import their history from CSV files or broker sync. TradeDrift reconciles raw fills into a clean trade ledger and runs a deterministic analytics engine on top, so the same trades always produce the same numbers.

```mermaid
flowchart LR
    A[Trade Sources] --> B[Ingestion]
    B --> C[Reconciliation]
    C --> D[Trade Ledger]
    D --> E[Analytics Engine]
    E --> F[REST APIs]
    F --> G[Dashboard]
    E --> H[AI Analysis]
```

<table>
  <tr>
    <td width="50%" valign="top"><b>Reconciliation</b><br><sub>Raw fills rebuilt into normalized trades with fees and funding costs.</sub></td>
    <td width="50%" valign="top"><b>Deterministic Analytics</b><br><sub>Win rate, expectancy, profit factor and drawdown, reproducible every run.</sub></td>
  </tr>
  <tr>
    <td valign="top"><b>Multi-Tenancy</b><br><sub>Every read and write scoped to its tenant.</sub></td>
    <td valign="top"><b>Auth & Billing</b><br><sub>JWT authentication and subscription billing across pricing tiers.</sub></td>
  </tr>
</table>

<sub><b>Stack:</b> Java · Spring Boot · PostgreSQL · REST APIs · JWT</sub>
